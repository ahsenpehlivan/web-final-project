# AlgoWiz — Data Structures & Algorithms Visualizer

![JavaScript](https://img.shields.io/badge/JavaScript-ES%20Modules-F7DF1E?logo=javascript&logoColor=black) ![CSS](https://img.shields.io/badge/CSS3-Responsive%20UI-1572B6?logo=css3&logoColor=white)

An interactive browser app for exploring how common algorithms and data structures work. The interface groups visualizations by topic and uses animations and learning content to make each step easier to follow.

## Explore the modules

- **Sorting:** bubble, selection, insertion, merge, and quick sort
- **Searching:** linear and binary search
- **Linked lists:** singly, doubly, and circular
- **Lists:** static and dynamic arrays
- **Stacks and queues:** LIFO and FIFO operations
- **Trees:** binary search tree and AVL tree

## Run locally

Serve the repository root with any static HTTP server. For example:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). The app uses browser JavaScript modules, so serving it over HTTP is more reliable than opening `index.html` directly.

## Stack

HTML, CSS, and vanilla JavaScript ES modules. No backend or build step is required.
